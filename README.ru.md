# AI Journal

Локальное веб-приложение для просмотра и изучения истории разговоров Claude Code и Codex. Читает JSONL-файлы сессий напрямую из `~/.claude/projects/` или `~/.codex/sessions/`.

## Возможности

- **Браузер проектов и сессий** — Все проекты сгруппированы по рабочей директории, полная история сессий в боковой панели
- **Фильтр боковой панели** — Введите ключевое слово для мгновенной фильтрации проектов и сессий; счётчик совпадений обновляется в реальном времени
- **Рендеринг разговоров** — Полный рендеринг Markdown, блоки кода с подсветкой синтаксиса (Shiki), таблицы GFM и списки задач
- **Визуализация вызовов инструментов** — Отображение каждого вызова инструмента Claude (Bash, чтение/запись файлов и т.д.) и его результата
- **Блоки размышлений** — Сворачиваемое отображение процесса рассуждений Claude
- **Статистика токенов** — Количество входных / выходных / кэшированных токенов и оценочная стоимость для каждой сессии
- **Полнотекстовый поиск** — `⌘K` для мгновенного поиска по всем сессиям
- **Экспорт в Markdown / Изображение** — Копирование любого сообщения как Markdown или скриншота одним кликом
- **Переключатель темы** — Светлая, тёмная или системная тема с сохранением настройки
- **Интерфейс на 11 языках** — Автоматически определяет язык браузера; смена в любой момент через языковой переключатель
- **Встроенные изображения** — Изображения в сообщениях (base64 или URL) отображаются сразу; клик для увеличения
- **Лайтбокс изображений** — Полноэкранный оверлей с размытием фона; закрывается клавишей `Esc` или кликом за пределами
- **Отображение slash-команд** — Сообщения `/команда` показываются как стилизованные чипы, а не XML
- **Вывод локальных команд** — Блоки вывода команд оболочки отображаются в стиле терминала; подробные предупреждения сворачиваются
- **Персистентная панель фильтров** — Настройки фильтров (мышление, инструменты, сообщения пользователя/Claude) сохраняются при смене сессии
- **Память сессии** — Последняя просмотренная сессия восстанавливается при перезагрузке через URL-параметры
- **Общие URL** — Скопируйте URL, чтобы поделиться точной сессией и позицией прокрутки (`?p=&s=&scroll=`)
- **Наверх** — Всплывающая кнопка появляется при прокрутке вниз; один клик возвращает к началу
- **PWA** — Устанавливается на рабочий стол или главный экран; автоматически обновляется без уведомлений при новом деплое

## Быстрый старт

**Требования:** [Claude Code](https://claude.ai/code) должен быть установлен и использован хотя бы один раз, чтобы локально существовала директория `~/.claude/projects/`.

```bash
# Клонировать репозиторий
git clone https://github.com/yuxianwen/claude-journal.git
cd claude-journal

# Установить зависимости
pnpm install

# Запустить сервер разработки
pnpm dev
```

Откройте [http://localhost:3000](http://localhost:3000) для просмотра всех сессий Claude Code.

## Источник данных

Все данные остаются на вашем компьютере. Приложение использует File System Access API браузера для прямого чтения файлов сессий; ничего не загружается на сервер.

Claude Code:

```txt
~/.claude/projects/
  └── <project-id>/
        ├── <session-id>.jsonl
        └── ...
```

Codex:

```txt
~/.codex/sessions/
  └── YYYY/MM/DD/
        ├── rollout-<timestamp>-<id>.jsonl
        └── ...
```

Каждый файл `.jsonl` соответствует одной сессии и содержит историю сообщений и доступные данные об использовании токенов.

## Горячие клавиши

| Сочетание | Действие |
|-----------|---------|
| `⌘K` | Открыть полнотекстовый поиск |
| `⌘\` | Показать / скрыть боковую панель |
| `Esc` | Закрыть поиск / лайтбокс |
