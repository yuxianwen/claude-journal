# AI Journal

تطبيق ويب محلي لتصفح ومراجعة سجل محادثات Claude Code و Codex. يقرأ ملفات JSONL مباشرةً من `~/.claude/projects/` أو `~/.codex/sessions/`.

## المميزات

- **متصفح المشاريع والجلسات** — جميع المشاريع مجمّعة حسب دليل العمل، مع السجل الكامل للجلسات في الشريط الجانبي
- **تصفية الشريط الجانبي** — اكتب كلمة مفتاحية لتصفية المشاريع والجلسات فورًا؛ يتحدث عدد النتائج في الوقت الفعلي
- **عرض المحادثات** — عرض Markdown كامل، كتل كود مع تمييز التركيب (Shiki)، جداول GFM وقوائم المهام
- **تصور استدعاءات الأدوات** — عرض كل استدعاء أداة قام به Claude (Bash، قراءة/كتابة الملفات، إلخ) ونتيجته
- **كتل التفكير** — عرض قابل للطي لعملية تفكير Claude
- **إحصائيات الرموز** — عدد رموز الإدخال / الإخراج / ذاكرة التخزين المؤقت لكل جلسة
- **البحث في النص الكامل** — يبحث `⌘K` في فهرس محلي يعيد بناء الجلسات المتغيرة فقط
- **تصدير إلى Markdown / صورة** — نسخ أي رسالة بصيغة Markdown أو لقطة شاشة بنقرة واحدة
- **محوّل السمة** — سمة فاتحة أو داكنة أو حسب النظام مع حفظ التفضيلات
- **واجهة بـ 11 لغة** — تكتشف لغة المتصفح تلقائيًا؛ التبديل في أي وقت عبر منتقي اللغة
- **صور تراعي الخصوصية** — تُعرض الصور المضمنة محليًا؛ ولا تُحمّل الروابط الخارجية إلا بعد موافقتك
- **صندوق الصور** — تراكب بشاشة كاملة مع تأثير ضبابي؛ يُغلق بـ `Esc` أو النقر خارجه
- **عرض أوامر الشرطة المائلة** — تُعرض رسائل `/الأمر` كرقائق منسّقة بدلاً من XML الخام
- **مخرجات الأوامر المحلية** — تُعرض كتل مخرجات الصدفة بأسلوب الطرفية؛ التحذيرات التفصيلية قابلة للطي
- **شريط فلتر دائم** — تُحفظ إعدادات الفلتر (التفكير، الأدوات، رسائل المستخدم/Claude) عند تبديل الجلسات
- **ذاكرة الجلسة** — تُستعاد آخر جلسة تمت زيارتها عند إعادة التحميل عبر معاملات URL
- **روابط الإشارات المرجعية** — انسخ الرابط لإعادة فتح الجلسة وموضع التمرير بدقة في المتصفح والجهاز نفسيهما (`?p=&s=&scroll=`). لا يحتوي الرابط على بيانات الجلسة ولا يمنح حق الوصول إلى الملفات المحلية.
- **العودة للأعلى** — يظهر زر عائم عند التمرير للأسفل كثيراً؛ نقرة واحدة للعودة للقمة
- **PWA** — قابل للتثبيت على سطح المكتب أو الشاشة الرئيسية؛ يتحدث تلقائياً وبصمت عند نشر إصدار جديد

## البدء السريع

**المتطلبات:** يجب أن يكون [Claude Code](https://claude.ai/code) مثبتاً وقد استُخدم مرة واحدة على الأقل لكي يكون `~/.claude/projects/` موجوداً محلياً.

```bash
# استنساخ المستودع
git clone https://github.com/yuxianwen/claude-journal.git
cd claude-journal

# تثبيت التبعيات
pnpm install

# تشغيل خادم التطوير
pnpm dev
```

افتح [http://localhost:3000](http://localhost:3000) لتصفح جميع جلسات Claude Code.

## مصدر البيانات

تبقى كل البيانات على جهازك. يستخدم التطبيق File System Access API في المتصفح لقراءة ملفات الجلسات مباشرةً، ولا يتم رفع أي شيء.

Claude Code:

```txt
~/.claude/projects/
  └── <project-id>/
        ├── <session-id>.jsonl
        └── ...
```

Codex:

```txt
~/.codex/sessions/
  └── YYYY/MM/DD/
        ├── rollout-<timestamp>-<id>.jsonl
        └── ...
```

يمثل كل ملف `.jsonl` جلسة واحدة ويتضمن سجل الرسائل واستخدام الرموز المتاح.
