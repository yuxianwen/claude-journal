# Claude Journal

تطبيق ويب محلي لتصفح ومراجعة سجل محادثات Claude Code. يقرأ ملفات JSONL مباشرةً من `~/.claude/projects/` — دون الحاجة إلى أي إعداد.

## المميزات

- **متصفح المشاريع والجلسات** — جميع المشاريع مجمّعة حسب دليل العمل، مع السجل الكامل للجلسات في الشريط الجانبي
- **عرض المحادثات** — عرض Markdown كامل، كتل كود مع تمييز التركيب (Shiki)، جداول GFM وقوائم المهام
- **تصور استدعاءات الأدوات** — عرض كل استدعاء أداة قام به Claude (Bash، قراءة/كتابة الملفات، إلخ) ونتيجته
- **كتل التفكير** — عرض قابل للطي لعملية تفكير Claude
- **إحصائيات الرموز** — عدد رموز الإدخال / الإخراج / ذاكرة التخزين المؤقت والتكلفة التقديرية لكل جلسة
- **البحث في النص الكامل** — `⌘K` للبحث الفوري عبر جميع الجلسات
- **تصدير إلى Markdown** — نسخ أي محادثة بصيغة Markdown بنقرة واحدة

## البدء السريع

**المتطلبات:** يجب أن يكون [Claude Code](https://claude.ai/code) مثبتاً وقد استُخدم مرة واحدة على الأقل لكي يكون `~/.claude/projects/` موجوداً محلياً.

```bash
# استنساخ المستودع
git clone https://github.com/yuxianwen/claude-journal.git
cd claude-journal

# تثبيت التبعيات
pnpm install

# تشغيل خادم التطوير
pnpm dev
```

افتح [http://localhost:3000](http://localhost:3000) لتصفح جميع جلسات Claude Code.

## مصدر البيانات

يقرأ التطبيق الملفات المحلية فقط — لا طلبات شبكة، لا بيانات مرفوعة. مسار بيانات الجلسة:

```
~/.claude/projects/
  └── <project-id>/
        ├── <session-id>.jsonl
        └── ...
```

كل ملف `.jsonl` يتوافق مع جلسة Claude Code واحدة ويحتوي على السجل الكامل للرسائل مع استخدام الرموز.
