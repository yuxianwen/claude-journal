# Claude Journal

Claude Code की बातचीत के इतिहास को स्थानीय रूप से ब्राउज़ और समीक्षा करने के लिए एक लोकल वेब ऐप। `~/.claude/projects/` से सीधे JSONL सत्र फ़ाइलें पढ़ता है — कोई कॉन्फ़िगरेशन आवश्यक नहीं।

## विशेषताएं

- **प्रोजेक्ट & सत्र ब्राउज़र** — कार्य निर्देशिका के अनुसार समूहीकृत सभी प्रोजेक्ट, साइडबार में पूर्ण सत्र इतिहास के साथ
- **बातचीत रेंडरिंग** — पूर्ण Markdown रेंडरिंग, सिंटैक्स-हाइलाइट कोड ब्लॉक (Shiki), GFM टेबल और टास्क लिस्ट
- **टूल कॉल विज़ुअलाइज़ेशन** — Claude द्वारा किए गए प्रत्येक टूल कॉल (Bash, फ़ाइल पढ़ना/लिखना आदि) और उसका आउटपुट
- **थिंकिंग ब्लॉक** — Claude की तर्क प्रक्रिया का संकुचित प्रदर्शन
- **टोकन आंकड़े** — प्रति सत्र इनपुट / आउटपुट / कैश टोकन की संख्या और अनुमानित लागत
- **फ़ुल-टेक्स्ट सर्च** — सभी सत्रों में तत्काल खोज के लिए `⌘K`
- **Markdown में एक्सपोर्ट** — एक क्लिक में किसी भी बातचीत को Markdown के रूप में कॉपी करें

## त्वरित शुरुआत

**पूर्वापेक्षाएं:** [Claude Code](https://claude.ai/code) इंस्टॉल होना चाहिए और कम से कम एक बार उपयोग किया गया होना चाहिए, ताकि `~/.claude/projects/` स्थानीय रूप से मौजूद हो।

```bash
# रिपॉजिटरी क्लोन करें
git clone https://github.com/yuxianwen/claude-journal.git
cd claude-journal

# निर्भरताएं इंस्टॉल करें
pnpm install

# डेव सर्वर शुरू करें
pnpm dev
```

सभी Claude Code सत्र ब्राउज़ करने के लिए [http://localhost:3000](http://localhost:3000) खोलें।

## डेटा स्रोत

ऐप केवल स्थानीय फ़ाइलें पढ़ता है — कोई नेटवर्क अनुरोध नहीं, कोई डेटा अपलोड नहीं। सत्र डेटा पथ:

```
~/.claude/projects/
  └── <project-id>/
        ├── <session-id>.jsonl
        └── ...
```

प्रत्येक `.jsonl` फ़ाइल एक Claude Code सत्र के अनुरूप है और इसमें टोकन उपयोग के साथ पूर्ण संदेश इतिहास है।

## कीबोर्ड शॉर्टकट

|---------|------|
| `⌘K` | फ़ुल-टेक्स्ट सर्च खोलें |
| `Esc` | सर्च बंद करें |
