# Claude Journal

Claude Code की बातचीत के इतिहास को स्थानीय रूप से ब्राउज़ और समीक्षा करने के लिए एक लोकल वेब ऐप। `~/.claude/projects/` से सीधे JSONL सत्र फ़ाइलें पढ़ता है — कोई कॉन्फ़िगरेशन आवश्यक नहीं।

## विशेषताएं

- **प्रोजेक्ट & सत्र ब्राउज़र** — कार्य निर्देशिका के अनुसार समूहीकृत सभी प्रोजेक्ट, साइडबार में पूर्ण सत्र इतिहास के साथ
- **साइडबार फ़िल्टर** — कीवर्ड टाइप करें और प्रोजेक्ट/सत्र तुरंत फ़िल्टर करें; मिलान गणना रियल-टाइम में अपडेट होती है
- **बातचीत रेंडरिंग** — पूर्ण Markdown रेंडरिंग, सिंटैक्स-हाइलाइट कोड ब्लॉक (Shiki), GFM टेबल और टास्क लिस्ट
- **टूल कॉल विज़ुअलाइज़ेशन** — Claude द्वारा किए गए प्रत्येक टूल कॉल (Bash, फ़ाइल पढ़ना/लिखना आदि) और उसका आउटपुट
- **थिंकिंग ब्लॉक** — Claude की तर्क प्रक्रिया का संकुचित प्रदर्शन
- **टोकन आंकड़े** — प्रति सत्र इनपुट / आउटपुट / कैश टोकन की संख्या और अनुमानित लागत
- **फ़ुल-टेक्स्ट सर्च** — सभी सत्रों में तत्काल खोज के लिए `⌘K`
- **Markdown / इमेज में एक्सपोर्ट** — एक क्लिक में किसी भी संदेश को Markdown या स्क्रीनशॉट के रूप में कॉपी करें
- **थीम स्विचर** — लाइट / डार्क / सिस्टम थीम, प्राथमिकता सहेजी जाती है
- **11 भाषाओं का UI** — ब्राउज़र की भाषा स्वतः पहचानता है; भाषा चयनकर्ता से कभी भी बदलें
- **इनलाइन इमेज डिस्प्ले** — संदेशों में एम्बेड की गई इमेज (base64 या URL) सीधे दिखाई जाती हैं; क्लिक करें बड़ा देखने के लिए
- **इमेज लाइटबॉक्स** — बैकग्राउंड ब्लर के साथ फुलस्क्रीन ओवरले; `Esc` या बाहर क्लिक से बंद करें
- **स्लैश कमांड डिस्प्ले** — `/command` संदेश कच्चे XML के बजाय स्टाइल्ड चिप्स के रूप में दिखाई देते हैं
- **लोकल कमांड आउटपुट** — शेल कमांड आउटपुट ब्लॉक टर्मिनल-स्टाइल UI में दिखाई देते हैं; विस्तृत चेतावनियाँ फोल्ड की जा सकती हैं
- **फ़िल्टर बार परसिस्टेंस** — फ़िल्टर सेटिंग्स (थिंकिंग, टूल्स, यूज़र/Claude संदेश) सेशन बदलने पर भी बनी रहती हैं
- **सेशन मेमोरी** — रिफ्रेश के बाद URL पैरामीटर से अंतिम देखा गया सेशन रिस्टोर होता है
- **शेयरेबल URL** — URL कॉपी करें और सटीक सेशन व स्क्रॉल पोजीशन शेयर करें (`?p=&s=&scroll=`)
- **टॉप पर वापस** — नीचे स्क्रॉल करने पर फ्लोटिंग बटन दिखाई देता है; एक क्लिक से पेज के शीर्ष पर वापस
- **PWA** — डेस्कटॉप या होम स्क्रीन पर इंस्टॉल करें; नया वर्जन डिप्लॉय होने पर ऑटो-अपडेट

## त्वरित शुरुआत

**पूर्वापेक्षाएं:** [Claude Code](https://claude.ai/code) इंस्टॉल होना चाहिए और कम से कम एक बार उपयोग किया गया होना चाहिए, ताकि `~/.claude/projects/` स्थानीय रूप से मौजूद हो।

```bash
# रिपॉजिटरी क्लोन करें
git clone https://github.com/yuxianwen/claude-journal.git
cd claude-journal

# निर्भरताएं इंस्टॉल करें
pnpm install

# डेव सर्वर शुरू करें
pnpm dev
```

सभी Claude Code सत्र ब्राउज़ करने के लिए [http://localhost:3000](http://localhost:3000) खोलें।

## डेटा स्रोत

ऐप केवल स्थानीय फ़ाइलें पढ़ता है — कोई नेटवर्क अनुरोध नहीं, कोई डेटा अपलोड नहीं। सत्र डेटा पथ:

```
~/.claude/projects/
  └── <project-id>/
        ├── <session-id>.jsonl
        └── ...
```

प्रत्येक `.jsonl` फ़ाइल एक Claude Code सत्र के अनुरूप है और इसमें टोकन उपयोग के साथ पूर्ण संदेश इतिहास है।

## कीबोर्ड शॉर्टकट

| शॉर्टकट | कार्य |
|---------|------|
| `⌘K` | फ़ुल-टेक्स्ट सर्च खोलें |
| `⌘\` | साइडबार दिखाएं / छुपाएं |
| `Esc` | खोज / लाइटबॉक्स बंद करें |
